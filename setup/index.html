Setup

You connect MetaTrader 5 to Kalibre Lab with the Kalibre Bridge add-on, a pairing code and one MT5 setting. Setup is done once. After that, the add-on sends data to the lab whenever MT5 is open.

Do your first setup on a demo account. Kalibre Bridge is read-only, and a demo account lets you learn the tool with no money at risk.

What you need

  • MetaTrader 5. On Windows, your broker's installer is enough; on macOS, the official MetaQuotes app.
  • A demo or live MT5 account with any broker.
  • The Kalibre Bridge add-on (KalibreKopru.ex5) and your license key. Both are on the Account page once you subscribe.

1. Add the add-on to MetaTrader 5

  1. In MT5, open File > Open Data Folder.
  2. Go to MQL5\Experts and copy KalibreKopru.ex5 there.
  3. Back in MT5, right-click Expert Advisors in the Navigator and choose Refresh. KalibreKopru appears in the list.

2. Create a pairing code in the lab

  1. Open the Connect MetaTrader 5 page. It shows the steps in order.
  2. Your browser generates a pairing code. Copy it with the Copy button.

The code starts with KLB1. Kalibre Bridge derives the encryption key from it. The code is stored in this browser and in the add-on's inputs, and is never sent to our servers. Do not share it.

3. Attach the add-on to a chart

  1. Drag KalibreKopru from the Navigator onto any chart.
  2. Open the Inputs tab.
  3. Paste the lab's code into Pairing code.
  4. Paste your license key (it starts with KLM-) from the Account page into License key.
  5. List the symbols you want under Symbols, separated by commas, e.g. EURUSD,GBPUSD,XAUUSD. Left empty, the add-on uses the first 12 symbols in Market Watch.
  6. Pick a Timeframe (M1, M5, M15, M30, H1, H4, D1 or W1) and click OK.

Kalibre Bridge cannot place, modify or close orders, so Algo Trading can stay off in MT5.

4. Allow the Kalibre address in MetaTrader 5

MT5 lets add-ons connect only to addresses you allow. You add the Kalibre address once.

  1. Open Tools > Options.
  2. Go to the Expert Advisors tab.
  3. Tick Allow WebRequest for listed URL.
  4. Add https://kalibremarkets.com to the list.
  5. Click OK. If you close the window with the X, the permission is not saved.

5. Check the connection

A Kalibre Bridge line appears in the top-left corner of the chart. The add-on checks your license first, which takes a few seconds, and then starts sending data. When the status reads connected, the count of sent documents goes up. The lab shows the connection status, your broker's name and the time of the last heartbeat.

Series refresh when a new candle closes: hourly on H1, daily on D1.

Common situations

What you see on the chartWhat to do
No WebRequest permissionRepeat step 4. Make sure the address is exactly https://kalibremarkets.com and that you clicked OK.
The add-on will not attach, a code error appearsCopy the code from the lab again. A character may be missing at the start or end.
License invalidCopy the key again from the Account page. You also see this if your subscription has ended or the key is already used on two MT5 accounts. The add-on retries every minute.
Relay unreachableCheck your internet connection. The add-on retries every few seconds.
The lab says "code does not match"The code in the add-on differs from the lab's. If you created a new code in the lab, paste the new one into the add-on too.
The connection drops after a whileThe bridge works while MT5 is open and the computer is awake. When the computer sleeps, data stops; it resumes on its own when MT5 is back.

Connecting with Tradier (US)

If you have an account with the US broker Tradier, you can connect it instead of MetaTrader 5. No add-on is needed; the lab talks to Tradier directly from your browser.

  1. Create an API access token in your Tradier account. We suggest a Sandbox token for your first try; Sandbox prices are delayed by 15 minutes.
  2. On the connect page, choose the Tradier tab, paste the token, pick the environment and press Connect.
  3. If you have several accounts, pick one. The Dashboard, the strategy builder and the optimizer now use Tradier data.
A Tradier token gives full access to your account. Kalibre makes read-only requests with it and never sends orders. The token is stored in this browser and sent only to Tradier. It is never sent to Kalibre servers. Disconnecting deletes it from this browser. Under Tradier's terms, this connection is for personal use.

Connecting with Alpaca (US)

If you have an account with the US broker Alpaca, you can connect it too. No add-on is needed; the lab talks to Alpaca directly from your browser.

  1. Create an API key pair in your Alpaca dashboard (Key ID and Secret). We suggest a Paper (simulated) account for your first try.
  2. On the connect page, choose the Alpaca tab, paste both keys, pick the environment and press Connect.
  3. The Dashboard, the strategy builder and the optimizer now use Alpaca data. If your watchlist is empty, your open positions are shown; if there are none, the symbols you add on the Dashboard.
On the free Alpaca plan, live prices come from the IEX exchange only, which is a small share of total market volume. Kalibre makes read-only requests with your keys and never sends orders. The keys are stored in this browser and sent only to Alpaca. They are never sent to Kalibre servers. Disconnecting deletes them from this browser. Use your own personal API keys.

Working without the add-on

You can also drag a candle file exported from MT5 (CSV or JSON) into the lab. Your browser reads the file locally. It is not uploaded.

The add-ons show their messages in English, or in Turkish if your MetaTrader 5 is set to Turkish.

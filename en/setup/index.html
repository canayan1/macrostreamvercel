Setup

Connecting MetaTrader 5 to Kalibre Lab takes one add-on, one code and one permission. You do it once; after that, your data reaches the lab on its own whenever MT5 is open.

We recommend doing your first setup on a demo account. The bridge never places trades, but it is a good habit to get to know a new tool on an account with no money at risk.

What you need

  • MetaTrader 5. On Windows, your broker's installer is enough; on macOS, the official MetaQuotes app.
  • A demo or live MT5 account with any broker.
  • The Kalibre Bridge add-on (KalibreKopru.ex5) and your license key. Both are on the License page once you subscribe.

1. Add the add-on to MetaTrader 5

  1. In MT5, open File > Open Data Folder.
  2. Go to MQL5\Experts and copy KalibreKopru.ex5 there.
  3. Back in MT5, right-click Expert Advisors in the Navigator and choose Refresh. KalibreKopru appears in the list.

2. Create a pairing code in the lab

  1. Open the lab and go to Connect MetaTrader.
  2. Your browser creates a pairing code for you. Copy it with the Copy button.

The code starts with KLB1 and is the key that encrypts your data. It lives only in this browser and in the add-on's settings; we never have a copy. Do not share it.

3. Attach the add-on to a chart

  1. Drag KalibreKopru from the Navigator onto any chart.
  2. Open the Inputs tab.
  3. Paste the lab's code into Pairing code.
  4. Paste your license key (it starts with KLM-) from the License page into License key.
  5. List the symbols you want under Symbols, separated by commas, e.g. EURUSD,GBPUSD,XAUUSD. Left empty, only the chart's own symbol is sent.
  6. Pick a Timeframe (M1, M5, M15, M30, H1, H4, D1 or W1) and click OK.

The add-on sends no orders, so you do not need to turn on Algo Trading in MT5.

4. Allow the Kalibre address in MetaTrader 5

MT5 only lets add-ons connect to the internet through addresses you allow. This step is there for your safety and is done once.

  1. Open Tools > Options.
  2. Go to the Expert Advisors tab.
  3. Tick Allow WebRequest for listed URL.
  4. Add https://kalibremarkets.com to the list.
  5. Click OK. If you close the window with the X, the permission is not saved.

5. Check the connection

A Kalibre Köprü line appears in the top-left corner of the chart. The add-on first checks your license (a few seconds), then starts sending data. Once the status reads bağlı (connected), the count of sent documents goes up. In the lab you will see the connection status, your broker's name and how many seconds ago the last heartbeat arrived.

Series refresh when a new candle closes: hourly on H1, daily on D1.

Common situations

What you see on the chartWhat to do
No WebRequest permissionRepeat step 4. Make sure the address is exactly https://kalibremarkets.com and that you clicked OK.
The add-on will not attach, a code error appearsCopy the code from the lab again. A character may be missing at the start or end.
License invalidCopy the key again from the License page. You also see this if your subscription has ended or the key is already used on two MT5 accounts. The add-on retries every minute.
Relay unreachableCheck your internet connection. The add-on retries every few seconds.
The lab says "code does not match"The code in the add-on differs from the lab's. If you created a new code in the lab, paste the new one into the add-on too.
The connection drops after a whileThe bridge works while MT5 is open and the computer is awake. When the computer sleeps, data stops; it resumes on its own when MT5 is back.

Working without the add-on

If you prefer not to install the add-on, drag and drop a candle file exported from MT5 (CSV or JSON) into the lab. The file never leaves your computer; it is read in your browser.

The add-ons currently show their on-chart status in Turkish or English depending on your MT5 language.
